shorts-analytics

shorts-analytics は、運営者が自分の YouTube チャンネルのアナリティクス(再生数・視聴維持率など)を読み取って動画制作の改善に使い、運営者が作った動画を運営者の指示でそのチャンネルにアップロードするための個人用ツールです。YouTube API サービスを使用しています。一般向けのサービスではありません。

shorts-analytics is a personal tool that reads analytics for the operator's own YouTube channel to improve future videos, and uploads videos the operator made to that channel when the operator tells it to. It uses YouTube API Services. It is not offered to the public.
