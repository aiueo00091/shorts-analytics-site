プライバシーポリシー

  • 本ツールは、運営者本人が許可した YouTube チャンネルのデータのみを、Google の OAuth を通じて読み取り専用(yt-analytics.readonly、youtube.readonly)で取得します。
  • 取得したデータは、運営者自身の動画制作の分析にのみ使用し、第三者に販売・提供・共有しません。
  • データは運営者が管理する環境(運営者の Google Cloud プロジェクトおよび Google ドライブ)にのみ保存されます。
  • アクセスの許可は、Google アカウントの設定(https://myaccount.google.com/permissions)からいつでも取り消せます。
  • 本ツールによる Google API から受け取った情報の使用は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

Privacy Policy

  • This tool reads data, read-only (yt-analytics.readonly, youtube.readonly), only for YouTube channels whose owner has authorized it through Google OAuth.
  • The data is used only to analyze the operator's own videos. It is never sold, provided or shared with third parties.
  • The data is stored only in environments the operator controls (the operator's Google Cloud project and Google Drive).
  • Access can be revoked at any time at https://myaccount.google.com/permissions.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
