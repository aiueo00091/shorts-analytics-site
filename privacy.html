プライバシーポリシー

  • 本ツールは YouTube API サービスを使用しています。本ツールを使用することで、YouTube 利用規約に同意したものとみなされます。Google のプライバシーポリシーは https://policies.google.com/privacy をご覧ください。
  • 本ツールは、運営者本人が Google の OAuth で許可した YouTube チャンネルのみを対象に、次の権限を使います: yt-analytics.readonly(アナリティクスの読み取り)、youtube.readonly(動画一覧・タイトル・概要欄の読み取り)、youtube.upload(運営者が作成した動画を運営者の指示でそのチャンネルにアップロード)。
  • 取得するのは、そのチャンネルの動画情報とアナリティクスの数値のみです。視聴者個人の情報は取得しません。Cookie は使用しません。
  • 取得したデータは、運営者自身の動画制作の分析にのみ使用し、第三者に販売・提供・共有しません。
  • データは運営者のコンピューターと、運営者のみがアクセスできる非公開のバックアップにのみ保存されます。認証トークンは運営者のコンピューターにのみ保存されます。
  • アクセスの許可は Google のセキュリティ設定(https://myaccount.google.com/permissions)からいつでも取り消せます。取り消された場合、保存したトークンとデータを削除します。
  • 本ツールによる Google API から受け取った情報の使用は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。
  • お問い合わせ: https://github.com/aiueo00091

Privacy Policy

  • This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy at https://policies.google.com/privacy.
  • It works only on the YouTube channel whose owner (the operator) authorized it through Google OAuth, with these scopes: yt-analytics.readonly (read analytics), youtube.readonly (read the channel's video list, titles and descriptions), youtube.upload (upload videos the operator made to that channel, when the operator tells it to).
  • It reads only that channel's video information and analytics figures. It collects no information about individual viewers and uses no cookies.
  • The data is used only to analyze the operator's own videos. It is never sold, provided or shared with third parties.
  • The data is stored only on the operator's computer and in a private backup only the operator can access. The authorization token is stored only on the operator's computer.
  • Access can be revoked at any time in Google's security settings at https://myaccount.google.com/permissions. When access is revoked, the stored token and data are deleted.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
